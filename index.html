Analytics Workflow

The repository is structured to demonstrate more than a dashboard: it shows the full path from data creation to validated analysis.

01GeneratePython creates reproducible customer and transaction data.
02ModelCustomer and transaction tables use a one-to-many relationship.
03AnalyzeSQL queries calculate KPIs, trends, segments and top customers.
04VisualizeStreamlit and Plotly provide interactive dashboard exploration.
05ValidateGitHub Actions checks data generation and SQLite integrity.
Synthetic-data analytics portfolio project. Risk segmentation is for demonstration only and is not a lending, underwriting, or creditworthiness model.
